# Terminal Cloud Brief

- Goal: benchmark whether Foundry can express a infrastructure deployment control plane without collapsing into the scenario's banned defaults.
- Style reference: `terminal-dark-07`
- Direction: `terminal-ops`
- Motif: `terminal-log-ribbon`
- Layout: `terminal-command-cascade`
- Complexity tier: `complex`
- Anti-slop constraints:
  - avoid fake hacker neon
  - avoid devtools dashboards that are only charts and cards
  - avoid unstructured console dumps with no command hierarchy
- Required interactions:
  - switch the active cluster
  - retry a deployment

# Example: Single Web Scenario

Prompt:

> Build one new `ui-testing` scenario for a finance operations webapp. Use a precise enterprise direction, avoid generic SaaS dashboard cards, create a runnable local fixture, write a Playwright charter, and produce a scorecard with any Foundry gaps.

Expected behavior:

1. Normalize any outside references into `ui-testing/research/`.
2. Write a scenario manifest with one direction, one motif, and one layout pattern.
3. Build a runnable local fixture with at least one real state change.
4. Write a charter under `ui-testing/charters/`.
5. Produce `brief.md`, `prompt-trace.json`, and `scorecard.json`.

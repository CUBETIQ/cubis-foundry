## How to choose a direction

Choose one primary style archetype and one supporting color or type mood. Name the direction in 2 to 5 words. Good directions sound like:

- quiet productivity
- premium dark command center
- editorial intelligence workspace
- playful guided consumer flow
- industrial operations console

For every direction, define:

- what the user should feel
- what should dominate visually
- what must stay restrained
- which common AI pattern to avoid

## Style archetypes

| Archetype | Best for | Visual signals | Motion | Avoid |
| --- | --- | --- | --- | --- |
| Quiet productivity | SaaS apps, planning, note tools | Soft surfaces, strong spacing, restrained color | Subtle | Too many cards |
| Editorial minimal | Content, portfolio, premium consumer | Generous whitespace, strong type, sparse chrome | Minimal | Weak information density |
| Premium dark | AI tools, media, command rooms | Deep surfaces, luminous accents, crisp borders | Smooth and restrained | Low contrast gray on gray |
| Industrial operations | B2B ops, logistics, field systems | Dense tables, clear status colors, durable controls | Minimal | Decorative glass effects |
| Data-dense analyst | Finance, analytics, admin tools | Compact type, consistent tabular rhythm, pinned context | Utility-first | Giant empty spacing |
| Playful consumer | Social, family, creator-lite | Warm color, rounded shapes, expressive empty states | Lively but fast | Infantilizing serious tasks |
| Trust-focused fintech | Banking, insurance, security | High contrast, crisp alignment, calm accent use | Controlled | Neon overload |
| Calm health and care | Health, wellness, support | Warm neutrals, reassuring spacing, clear steps | Gentle | Cute visuals for serious moments |
| AI copilot workspace | Assistant UIs, docs, work copilots | Split panes, prompt area, result canvas, citation rhythm | Purposeful | Chat-only layout for every task |
| Creative studio | Visual tools, editors, builders | Canvas plus inspector, modular panels, layered controls | Direct manipulation | Hiding tools behind too many menus |

## Color moods

Use color roles before specific hex values.

| Mood | Primary use | Typical balance |
| --- | --- | --- |
| Trustworthy | Finance, enterprise, healthcare | Cool base, one restrained accent |
| Energetic | Consumer growth, creation | Neutral base plus vivid action color |
| Premium | High-end products, media | Deep neutrals, one metallic or luminous accent |
| Calm | Health, productivity, support | Warm neutrals, low-saturation accent |
| Industrial | Operations, infra, admin | Strong neutrals, signal colors for status |
| Playful | Consumer, education, family | Multiple soft accents on quiet base |

## Type pairings

Prefer accessible, widely available families.

| Use case | Pairing |
| --- | --- |
| Modern product UI | Inter + JetBrains Mono |
| Editorial app | Inter + Source Serif 4 |
| Premium consumer | Manrope + Fraunces |
| Technical workspace | IBM Plex Sans + IBM Plex Mono |
| Friendly consumer | DM Sans + Nunito Sans |
| Serious enterprise | Geist + JetBrains Mono |
| Calm product | Instrument Sans + Source Serif 4 |
| Dashboard heavy | Archivo + IBM Plex Mono |

## Chart guidance

Match chart type to the question.

| Question | Good chart types | Avoid |
| --- | --- | --- |
| Trend over time | Line, area | Pie |
| Part-to-whole | Stacked bar, donut with few slices | Many-slice pie |
| Comparison | Bar, grouped bar | Radar |
| Distribution | Histogram, box plot | Smoothed line with no bins |
| Relationship | Scatter | Decorative bubble chart |
| Funnel progression | Funnel, step bars | Pie |

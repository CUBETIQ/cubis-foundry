# Output Template

Use this structure for full design blueprints and implementation handoffs.

# [Project or feature name]

## 1. Product summary
- Product type
- Primary users
- Core jobs to be done
- Business or user goals

## 2. Design direction
- Direction name
- Visual tone
- Density
- Hierarchy strategy
- Motion style
- Key risk to avoid

## 3. System decisions
- Information architecture
- Navigation model
- Type and spacing logic
- Color role logic
- Core component primitives
- Shared states

## 4. Surface plan
- Primary entry points
- Key screens
- Dominant interactions
- Platform-specific affordances
- Known constraints

## 5. Responsive and adaptive behavior
- Shared elements across surfaces
- Adaptive changes by surface
- Breakpoints or size classes
- Table, form, and filter behavior across widths

## 6. Accessibility, motion, and performance
- Accessibility requirements
- Motion principles
- Performance constraints

## 7. Implementation handoff
- Component list with important variants
- State map
- Interaction notes
- Suggested frontend architecture notes
- Open questions or risks

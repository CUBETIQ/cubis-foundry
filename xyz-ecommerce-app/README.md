# XYZ Ecommerce

Flutter-first buyer marketplace validation app for Cubis Foundry.

## Default account

- Username: `root`
- Password: `123`

## Core flow

1. Complete onboarding
2. Log in with the default buyer account
3. Browse the fashion collection
4. Open a product detail page
5. Add a product to bag
6. Complete checkout
7. Review the order in the Orders tab
